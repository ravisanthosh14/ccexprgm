CAREPLUS MEDICAL STORE - SIMPLE WEBSITE

Files:
- index.html : webpage structure
- style.css  : design and responsive layout
- script.js  : product list, search, filters, and demo cart

HOW TO RUN:
1. Extract medical_items_website.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in a web browser.
4. Internet is only needed for the optional Google Fonts; the website itself works offline.

NOTE:
This is a front-end learning/demo project. Prices and products are sample data.
It does not process payments, accept real orders, or provide medical advice.
Replace the demo contact email and sample product information before using it for a real business.
